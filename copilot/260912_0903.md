## 第一阶段：先统一系统状态

定义系统运行状态：

```c
typedef enum {
    SYS_OFF = 0,
    SYS_ON,
    SYS_SETTING_TIMER,
    SYS_SETTING_ALARM,
    SYS_ALARM
} SystemMode_t;
```

也可以把 `SYS_ALARM` 作为报警标志，而不是独立状态：

```c
typedef struct {
    U8 power_on;
    U8 fan_level;
    U8 alarm_active;
    U8 setting_mode;
    U16 timer_seconds;
    U16 timer_remaining;
    U16 alarm_rpm;
} AppState_t;
```

更推荐第二种，因为报警时系统仍然是开机状态。

开关机时统一执行：

```c
void App_ResetRuntimeState(void)
{
    fan_level = 0;
    timer_remaining = 0;
    alarm_active = 0;
    alarm_output_off();
    Fan_SetSpeed(0);
    DisplayGraphicsSet(0);
}
```

然后由 `power.c:10-35` 调用：

```text
Power_Off()
    -> 清除运行参数
    -> 关闭PWM
    -> 清除报警输出
    -> 关闭显示和背光

Power_On()
    -> 清除运行参数
    -> 开启显示和背光
    -> PWM保持关闭
```

这样按键1和 PLC 无论从哪个方向触发，行为都一致。

## 第三阶段：完成定时功能

建议把“定时设置”定义为：

> 设置 PWM 输出持续时间，时间到后自动关机或关闭风扇。

需要先明确最终业务是哪一种：

- 定时到期后整机自动关机；
- 定时到期后只关闭 PWM，显示仍保持；
- 定时设置的是 PWM 启动延时。

从你的描述看，最像第一种：风扇运行指定时间后自动关机。

推荐参数：

```c
U16 timer_minutes;
U16 timer_remaining_seconds;
bit timer_running;
```

利用已有的 `Sys1ms`，在主循环中分频：

```text
1 ms中断
    -> Sys1ms = 1

主循环
    -> 每1000ms timer_remaining_seconds--
    -> 到0后 Power_RequestOff(POWER_SRC_TIMER)
```

不要在中断里直接调用 `Power_Off()`、显示函数或蜂鸣器函数。

设置流程：

```text
开机状态
    KEY4 长按
        -> 进入 SYS_SETTING_TIMER
        -> 显示当前定时时间

SYS_SETTING_TIMER
    KEY2 短按 -> 时间减少
    KEY3 短按 -> 时间增加
    KEY4 短按 -> 保存定时参数，进入 SYS_SETTING_ALARM
    KEY4 长按 -> 保存并退出设置

SYS_SETTING_ALARM
    KEY2 短按 -> 报警转速减少
    KEY3 短按 -> 报警转速增加
    KEY4 长按 -> 保存并退出设置
```

注意：进入设置后，KEY2/KEY3 不应再改变风扇档位。

## 第四阶段：实现转速报警

报警判断不要直接使用瞬时 `fan_rpm`，建议加入连续确认和恢复延时：

```text
风扇开启后等待启动时间，例如3秒
    -> 避免刚启动时RPM为0立即报警

RPM连续低于报警值，例如500ms
    -> alarm_active = 1

RPM连续恢复到报警值以上，例如1000ms
    -> alarm_active = 0
```

如果需求是“超速报警”，判断方向改为：

```c
fan_rpm > alarm_rpm
```

如果是风扇堵转或低速报警，则使用：

```c
fan_rpm < alarm_rpm
```

报警模块负责：

```text
alarm_active = 1
    -> P15输出报警电平
    -> 蜂鸣器按节奏鸣叫
    -> P24/P25交替输出

alarm_active = 0
    -> P15恢复正常电平
    -> P24/P25关闭或恢复默认状态
    -> 蜂鸣器关闭
```

先增加独立的 GPIO 定义，不要直接在 `main.c` 中操作寄存器：

```c
#define ALARM_OUT_INIT()  P15_OUT

#define ALERT_TX_INIT()   P24_OUT
#define ALERT_RX_INIT()   P25_OUT
```

P24/P25 交替输出需要明确周期。例如可先定义：

```text

    0~100ms：P24=1，P25=0
    100~200ms：P24=0，P25=1
```

这可以由 1 ms 节拍在 `Alarm_Task()` 中实现，不建议使用 UART 外设。虽然需求称为 TX/RX，但如果只是报警交替电平，就应按普通 GPIO 处理。

- P15 报警有效电平是高还是低；

- P24/P25 是否真的要作为 UART 通信，还是仅使用 TX/RX 对应的物理引脚。
